# Vetted Video Channels

The pre-vetted channel database for classroom media. Reliable channels — large subscriber bases, consistent upload history, rarely delete content, generally ad-light within educational content — grouped by area. Each row's name is the search key: resolve it to a live channel home page at build time rather than storing a URL that can rot. Treat the list as a starting point, not a closed set.
