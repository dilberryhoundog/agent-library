Prompt Builder

Fill in the builders this session needs and copy the prompt into Claude Code. Every builder is optional; empty ones stay out of the prompt.

Editing the loadout Click an option to change or delete it. Help text and agent instructions are editable in place. Changes stay in this browser until you save them from Utilities.

How this works

Fill in builders, pick options, and the prompt assembles in the panel on the right. Copy it into a Claude Code session, or write it to a file.

Build

Each tile is a builder: one section of the prompt. Open it, fill it in, and come back. A builder only appears in the prompt once it has content, under a heading the agent reads. The number on a tile is its position in the prompt; set that order in Utilities.

Write builders take free text. Choose builders offer options from the loadout. An option marked + sends the agent a longer instruction than its label; hover it to read what will be sent. Deliverables picked in Output can be placed inside the Process sequence, nested under the stage that produces each one.

Launch

Assembles the claude command that starts the session. Pick a preset or build it flag by flag, then copy it into the terminal. Resume lists recent sessions from a project folder you choose and adds --resume for the one you pick.

Recipes

Reusable blocks of text that join the prompt verbatim, before or after the builders. Switch one on to include it. Add or edit recipes in Edit mode.

Utilities

What this browser can do, the file path and prompt folder, the order and visibility of builders, standalone utility prompts, and the loadout itself: save it into this file, export it, import another, or reset to the one in the file.

Edit mode

Turns every option into something you can change or delete, and opens help text, placeholders and agent instructions for editing. Entering Edit clears the prompt. Changes are held in this browser until Utilities → Save writes them into the page's own source.

Loadouts

A loadout is everything the builders offer: options, help text, agent instructions, order and visibility, plus the launch options. Keep one per kind of project and swap them with Export and Import. Import replaces the whole loadout, so a file must carry every builder.

Keyboard

Esc returns to the dashboard from a builder. Enter in a list adds a row below. Alt + ↑ / ↓ moves a focused stage or builder row.

Privacy

Nothing leaves this browser. The only network request is the font stylesheet, and the page works without it.

Prompt

A single local file. Builders are fixed in the page; everything they offer lives in the loadout block at the top of the source, editable in place or by hand. Nothing leaves the browser. Saving into this file and remembering folders need a Chromium browser; Utilities reports what this one can do.
