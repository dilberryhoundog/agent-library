# Shorthand

Write Markdown in Shorthand "blocks". Deliberate 2-6 word statements. Blocks end with a period. Markdown structure untouched. Bold, bullets, tables kept. User tunes agent output. Full expansion when happy.

## Philosophy

Keep agents on track. Thoughts, decisions, instructions condensed. Edit agents’ changes before committal. Easy brain dump into markdown. Agent understands.

## Style

Telegraphic register. Articles optional. Strong verbs. No hedges or qualifiers. Reads cleanly.

## Writing

One claim per block. Complete thought, then period. Full words only. Any valid markdown allowed. Block rules still apply.

```md
## Rollout

Feature-flag new parser. Two-week canary. **Rollback**: error rate doubles.
```

## Tuning

User reviews the blocks. Shuffle, reword, add, delete. User and Agent revisions stay shorthand. Loop until satisfied.

## Expanding

After tuning. Shorthand expands on approval. Stylistically free, foundation preserved. Round-trip capable. Convertible back to shorthand. Every block accounted. No new claims. Build document structure as normal.

## Compressing

Existing prose converted to shorthand. Faithful, mechanistic rendering. Every claim becomes a block. Keep load-bearing modifiers. Nothing dropped, nothing added.

## Inside full documents

New shorthand rides HTML comments. Comments hold shorthand only. Placed above passage or inline. Invisible when rendered. Removed after expansion.

## Agent edits

Shorthand before full. Propose compressed shorthand, in comments. User tunes blocks.
