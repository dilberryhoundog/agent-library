## Task
Build a html artifact suite. The core layout, styles and js can all be in a shell template. Then page templates with all prerequisite styles and scripting so they can be edited into the shell.

## Context
**Read first**
- `extensions/artifacts/prompt-builder/prompt-builder.html` — The most recent, active example of styling and layout.
- `dev/workspace/reviews/mock-4-proposals.html` — The best representation of a review or shell document. key pieces: theme selector, cards with colour sidebar, floating copy & text buttons.

## Goals
- User can navigate directly to all files or sites in question, to check original content.
- User can see clearly where the work originates from (branch, issue, pr)
- User can always return to the agent with a prompt that progresses the context or conversation
- Agent can build artifacts repeatedly with consistent features and styling. focusing on content.
- Agent is token efficient. strategically building or editing a document.
- Artifacts preserve users history (decision and response) when updating. but doesn't enter return prompt unless edited.

## Features
- page shell — shell for every page template. Has all the base styling, layout and scripting. copy prompt
- review page — agent presents findings or results. user can approve and comment on each change
- interview page — agent asks user a series of questions, to gain further insight.
- demo page — active demonstrate a portion or component.
- options page — provide the user options to choose from. recommended, extra comments
- issue breakdown — core issue, investigation results, additional comments.
- link to site — collapsed link to file or location in question when available.
- quoted user conversation — quote section for users comments from the chat, that apply to card contents.
- filterable tags — show only relevant cards per filter. (eg integrate, your call, defer)
- formatted diffs — colour red gray green (remove, keep, add). The + or - marker colored & in a consistent margin next to content. not in content box.
- return prompting — each page builds a return prompt for the agent, with advanced context guiding next steps.
