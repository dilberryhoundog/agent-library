# Plan: DraftHorse Rule Set (extensions/rules/DraftHorse.md)

Status: **On Hold** — shelved, not decided-dead. Sources: concept 14, TODO 12. Decision in [new-concepts-discussion.md](new-concepts-discussion.md) §14 (superseded entry), [todos-discussion.md](todos-discussion.md) §12.

## Context handover

Originally: a consumer-facing operator's manual (utilities, notation, step handling, handover handling, consumer conventions) copied into global or project CLAUDE context, structured around the executor's five questions (what's a step / when do I start one / when am I done / what's binding / what do I do with a cited link). Deliberate duplication of framework content was licensed — rules sit outside the SSoT convention (SSoT applies within DraftHorse documents, not where runtime reflects them).

Superseded by the self-describing direction: documents carry their own operator's manual via the preamble + machinery headings + handover template + frontmatter stamp. Rules are intentionally redundant.

## Revisit trigger

Only if a need survives that documents can't carry themselves. Known candidate residue: dispatch/surfaces guidance for the MAIN agent (which skill preambles never reach — the main agent decides where to run a skill before reading it); if that need materialises, the rule's remit is surfaces.md content in rule form, nothing else.

None. `extensions/rules/DraftHorse.md` stays a stub (its TODO comments may be replaced with a one-line "On hold" note pointing here, at the executor's discretion during any nearby pass).
