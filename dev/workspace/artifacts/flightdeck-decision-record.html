Decision & Convention Record

Every decision, convention and term as you stated it, grouped by area. Click any text to edit it in place; change a status from its menu. Export writes the whole record as JSON; Save writes it back into this file.

How this works

The record lives in a JSON block at the top of this file's source. The page renders it; edits are held in this browser (localStorage) until you Export or Save.

Editing

Titles, statements, reasons, quotes, tags and dates are editable in place — click, type, click away. Status is a menu on each card. Delete removes a card; + Record adds a blank one to the area you choose.

Export

Downloads decision-record-YYYY-MM-DD.json carrying the whole record with your edits. Any browser.

Save into file

Chromium only. Bind this file once (a file picker pointing at this very page); after that Save rewrites the JSON block in place. The handle is remembered in this browser.

Import

Replaces the whole record with a JSON file of the same shape.
A single local file. The record is the JSON block at the top of the source; edit it there or here. Nothing leaves the browser.
