Handover documents take the **handover-variant** preamble (byte-exact from the common brief) — NEVER the universal text. This is the sweep's known hazard: a prior corpus-wide preamble sweep gave these files the universal text and had to be undone.

## Work per file

- **Preamble** — replace the old quote-block preamble with the variant paragraph.
- **De-hold** — one de-hold-shaped start clause each in `setup`, `media-processing`, `mark-review` per the inherited-scope count (deliver-without-renderer counted none). Judge per the three classes; trim class-1 sites; record judgment.
- **Slots** — the slot grep counted zero in these files; verify and record.
- **Vocabulary** — "error drain"/"problem step" → error-step vocabulary. In a handover the correct frame is the variant preamble's own: the parent document covers error handling. Verify zero retired vocabulary after.
- **Condition lists** — verify list form; convert any prose block per the common brief.
- **Directives / functions** — child steps take directives like any step. Functions: declare only where a child step plainly performs a catalogued shape (a per-item loop, a genuinely dormant branch). Handovers carry no exit steps — do NOT add success or error declarations; an optional child error step, if one exists, keeps its role but check it against the variant preamble's "unless an optional child error step is present".
- **No parent naming** — a handover names no specific parent; flag any pointer at the parent document (do not fix beyond vocabulary scope).
