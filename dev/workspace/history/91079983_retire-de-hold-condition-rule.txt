## No, skills in the wild carry none of this

Skills in the wild are prose procedures. No start conditions, no finished conditions, no eligibility rules. An agent reads them and uses judgment. DraftHorse's conditions are already far more machinery than the field runs — de-hold, precedence and scoping are machinery on top of machinery.

The failure de-hold guards against — a step re-admitting itself forever — is a state-machine failure, not an agent failure. A state machine re-evaluates a predicate with no memory of what it just did. An agent has the transcript. It does not re-gather requirements because "the skill has been invoked" still reads true; it knows it just gathered them.
